MYROメルマガ運用ガイド

MYROのメルマガは、Shopify Email の「独自コード」に手書きのHTMLを貼り付けて配信しています。このガイドは、その作り方・デザイン・配信時期と、これまでに実際に起きたエラーと回避策をまとめたものです。

対象　MYROチームのシステム担当更新　2026年10月7日

01この資料について

  • 配信ツール：Shopify 管理画面 →「Messaging（Shopify Email）」→ メッセージを作成 → テンプレート選択で「独自コード」→ HTMLを貼り付け
  • 制作ファイルの保管場所：Desktop/myro_claude/メルマガ/（1通＝1ファイルのHTML）
  • 元になった実配信：2026年9月の販売会②（4通）と、10月4日の No Measure Line（3通）
  • 前提：配信は販売会ごと。商品・会期・在庫は毎回 Shopify から取り直す

03配信スケジュール

通常の販売会は1回につき4通を配信します。販売会は土曜21:00開始、翌日23:59終了が基本です。

2前日 19:00前日告知全ラインナップ、購入方法、FAQ。この時点で商品ページを公開し、購入方法の確認を促す

04作り方

配信は、オーナーとシステム担当の間で次の5段階で進めます。オーナーのOKとテスト配信の確認が済むまで、配信予約はしません。

配信までの流れ

  1. 内容をまとめるオーナー
    送りたいメルマガの内容をまとめて、システム担当に送る
  2. デザインを作るシステム担当
    下の「デザイン作成の手順」でHTMLを作る
  3. チェックを受けるオーナー
    完成したデザインを見せて、OKをもらう。修正があれば2に戻る
  4. テスト配信システム担当
    自分宛てに送り、URLが生きているか、画像がちゃんと表示されるかを確認する
  5. 配信を予約するシステム担当
    Shopify Email で配信日時を予約する

デザイン作成の手順

上のステップ2の中身です。忘れやすいのは1の商品登録の確認と、4・5のチェックです。

  1. 商品データを取る：Shopifyで販売開始タグ（例：販売開始_20261004_1900）で絞り込み、デザイン名・ハンドル（URL）・画像URL・在庫を揃える。会期・サイズ締切・発送日は商品説明文のスケジュール欄が正。商品や画像がShopifyに登録されていない場合は、作業を止めてオーナーに連絡する
  2. ベースを選ぶ：同じ型の過去配信を複製する（「ファイル一覧」参照）。10月分は Node スクリプト メルマガ/_tools/build_nm_mails.js で生成しており、商品配列を書き換えて node build_nm_mails.js で再生成できる（出力先は絶対パスなので環境に合わせて変更）
  3. 文面と画像を入れる：画像は商品登録の cdn.shopify.com URL。重い写真は &amp;width=800 を付けて縮小（次の章）
  4. スマホ幅で見る：375px幅で表示し、見出しの折り返し、1文字だけの行（「た.」「す.」）、英字ラベルの途中改行を直す。ヘッドレスChromeなら chrome.exe --headless=new --window-size=375,1000 --screenshot=... で確認できる
  5. 配信前チェック：このガイドのチェックリストをすべて通す（特に {{ unsubscribe_link }} と &amp;）
  6. Shopifyに貼る：「独自コード」にHTMLを貼り、件名を入力。保存時にエラーが出たら行番号を見て次の章の事例と照らす
  7. テスト送信：自分宛てに送り、スマホ実機でリンクを押して確認する。編集画面のプレビューではリンクが動かないことが多い

オープン直後の配信は、送信の直前にもう一度在庫を確認します。完売・受付中の表示や、「○時○分に完売」「○人が来店」といった数字が、送信時点の事実と合っている必要があるためです。

05Shopify Email の技術要件

保存エラーを出さないための必須ルールは4つです。いずれも実際にエラーや表示崩れを起こしたものです。

ルール書き方守らないと
配信停止リンク{{ unsubscribe_link }} を単体で置く。この変数は <a> タグごと出力されるので、色は <style> の .unsub a{…!important} で当てる無い＝保存エラー。href の中に入れる＝style="color:..." が文字で見えてリンクも壊れる
開封計測</body> の直前に {{ open_tracking_block }} を1行無い＝保存エラー
URLの &&amp; と書く（例：…jpg?v=1791021357&amp;width=800）「N行目の構文が有効ではありません」が & の数だけ出る
ボタン<table><tr><td> の td に背景色と余白を持たせ、中に <a> を置く<a style="display:block"> 単体だとプレビューで右にずれる

画像

  • 画像は Shopify の商品登録で登録されているものを使う（https://cdn.shopify.com/... のURL）。商品や画像が未登録の場合は、自分で用意せずオーナーに連絡する
  • data:image/...（base64埋め込み）は多くのメールアプリで表示されない。配信前に data:image で検索して0件を確認
  • 写真の元ファイルは 3024×4032・約1.5MB。&amp;width=800（メインは1000、小さい写真は520）を付けるとJPGは70〜180KBになる。PNGは縮小しても約0.4MBで、形式変換は効かない

その他

  • プリヘッダー（受信トレイで件名の下に出る文）は、本文先頭の display:none の div に書く。続きを拾わせないため、直後に空白文字の div を置く
  • 日本語やローマ数字を含む商品ハンドルはURLエンコードする（例：design-ⅳ → design-%E2%85%B3）
  • Outlook（Windows版）はグラデーションや角丸を表示しない。崩れはしないが、単色・四角になる
  • フッターには特定電子メール法のため、名称・住所・配信停止リンクを必ず入れる

07文面のルール

文末は句点「。」ではなく半角ピリオド「.」で統一し、価格は載せません。

  • 挨拶は「こんばんは、MYROです.」（昼配信は「こんにちは」）
  • やわらかい敬語（〜いただけます／〜となります）。「！」も使わず「.」にする
  • 価格は表示しない。ラインナップはデザイン名と一行コピーまで。価格は商品ページで見てもらう
  • 在庫数は書かない。「数量限定」「売り切れ次第終了」の表現にとどめる。ただし「1点限定」「3点限定」などの数は、Instagramなどですでに公開している場合は書いてよい
  • 無償のサイズお作り直しは1回のみ（MYRO公式ストアでフィッティングチップを購入・計測した方が対象）。「回数制限なく」は誤り
  • 煽りは事実ベースの言い切りで。「争奪戦」のような誇張は使わない。実際の数字（「19時10分に完売」「74人が来店」）は効果が高い
  • 未確定の箇所は【　】で仮置きし、配信前に必ず消す

件名とプレビューテキスト

  • 件名は先頭を【　】にし、中に開けたくなるフックを入れる。スマホでは前半20文字ほどしか見えないので、日時と要点を前に置く
  • プレビューテキストは件名と重ならない補足を1文で。HTML先頭のプリヘッダーに書く
